# TikLive Web — веб-версия, как у TikFinity

Стример открывает сайт, регистрируется по e-mail и сразу работает в браузере. Ничего устанавливать не нужно: подключение к TikTok LIVE держит сервер, а оверлеи — это личные ссылки, которые добавляются в OBS или TikTok LIVE Studio.

```
браузер стримера ──(панель /app, сессия)──▶  TikLive Web  ──▶ TikTok LIVE (по нику)
OBS / LIVE Studio ──(/o/<токен>/?w=alerts)──▶  (сервер)    ──▶ Claude (ИИ), Lemon Squeezy (подписка)
```

## Что умеет

- **Аккаунты.** Регистрация и вход по e-mail. Пароли хранятся только в виде хеша (scrypt), сессия живёт в защищённой cookie 30 дней.
- **У каждого пользователя своё пространство:** свои правила, цели, очки зрителей, статистика и подключение к TikTok. Данные одного стримера не видны другому.
- **Личные ссылки на оверлеи** `/o/<токен>/?w=…`. Работают в OBS без входа в аккаунт. Если ссылка утекла, кнопка «Сменить ссылки оверлеев» мгновенно отключает старые.
- **Эфир не прерывается.** Подключение к TikTok держит сервер, даже когда вкладка браузера закрыта. После перезапуска сервера подключение восстанавливается само.
- **ИИ-ответы** идут через ключ Anthropic сервера. Модель задаёт сервер, а не пользователь. Лимиты: 500 ответов в месяц для Pro и 100 на пробный период.
- **Подписка Pro.** 7 дней бесплатно с момента регистрации, дальше $8 в месяц. Ключ Lemon Squeezy вводится на вкладке «💎 Pro» и привязан к аккаунту, а не к компьютеру.
- **Защита:** от CSRF (изменения принимаются только в формате JSON, cookie с SameSite=Lax) и от подбора пароля (10 попыток за 15 минут с одного IP).

**Только в приложении для ПК:** нажатие клавиш в играх и прямое управление OBS. Сервер физически не может нажимать клавиши на компьютере стримера. Остальное работает в браузере.

## Переменные окружения

| Переменная | Обязательна | Что это |
|---|---|---|
| `SESSION_SECRET` | да | случайная строка ≥ 32 символов: `openssl rand -hex 32`. После запуска не меняйте |
| `SIGN_API_KEY` | очень желательно | ключ Euler Stream для подключения к TikTok. Без него сервер быстро упрётся в лимиты подключений |
| `ANTHROPIC_API_KEY` | для ИИ | ключ Claude. Без него вкладка ИИ сообщает, что ИИ не подключён |
| `LS_STORE_ID`, `LS_PRODUCT_ID`, `CHECKOUT_URL` | для продаж | данные магазина Lemon Squeezy |
| `AI_MODEL`, `AI_EFFORT`, `PRO_MONTHLY_LIMIT`, `TRIAL_LIMIT` | | `claude-opus-5-5`, `low`, 500, 100 |
| `DATA_DIR` | | где хранить данные (`/data` в Docker) — нужен постоянный диск |
| `TRUST_PROXY=1` | за прокси | доверять заголовкам `X-Forwarded-*` (Render, Railway, Fly, nginx) |
| `SECURE_COOKIES=1` | при HTTPS без прокси | ставить cookie только по HTTPS |
| `ALLOW_SIGNUP=0` | | закрыть регистрацию (например, на время бета-теста) |
| `PORT` | | 8080 |

## Запуск

Локально:
```bash
SESSION_SECRET=$(openssl rand -hex 32) npm run web
# откройте http://localhost:8080
```

Docker на VPS (за Caddy или nginx с HTTPS):
```bash
docker build -f hosted/Dockerfile -t tiklive-web .
docker run -d --restart=always -p 8080:8080 -v tiklive-web:/data \
  -e SESSION_SECRET=... -e SIGN_API_KEY=... -e ANTHROPIC_API_KEY=... \
  -e LS_STORE_ID=... -e LS_PRODUCT_ID=... -e CHECKOUT_URL=... tiklive-web
```

Render или Railway: Web Service из репозитория, Dockerfile — `hosted/Dockerfile`, постоянный диск в `/data`, переменные из таблицы.

Сервер должен работать **постоянно**. Бесплатные тарифы, которые «засыпают» без трафика, не подходят: эфиры стримеров будут обрываться.

## Масштаб и стоимость

- Один процесс держит всех пользователей. Неактивные пространства выгружаются из памяти через 30 минут. Ориентир: сотни одновременных эфиров на VPS с 2 ГБ памяти — это оценка, под нагрузкой не проверялась. Для тысяч эфиров нужно несколько серверов и балансировка по пользователям — это следующий этап.
- Главные расходы: VPS (от ~$6 в месяц), Euler Stream (по их тарифу — зависит от числа подключений) и Claude (около $3 в месяц на активного Pro-пользователя при лимите 500 ответов).

## Чего пока нет

- **Восстановления пароля по e-mail.** Нужен почтовый сервис (Resend, Postmark и т.п.). Пока пароль можно сбросить только вручную.
- **Автоматической активации Pro после оплаты.** Сейчас ключ из письма Lemon Squeezy вставляется вручную. Следующий шаг — webhook Lemon Squeezy, чтобы Pro включался сам.
- **Входа через Google или TikTok.**
