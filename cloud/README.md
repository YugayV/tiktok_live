# TikLive Cloud — ИИ-ответы через ваш сервер

Небольшой сервис, который отвечает на вопросы зрителей за подписчиков TikLive Pro.

- **Ключ Anthropic хранится только на сервере.** В приложение он не попадает, извлечь его оттуда нельзя.
- **Подписку проверяет сервер.** Перед каждым ответом он проверяет ключ лицензии через Lemon Squeezy: ключ должен быть выдан для вашего магазина и продукта, подписка — активна. Даже если вырезать проверку из приложения, ИИ без оплаты работать не будет.
- **Пробный период тоже серверный.** Он привязан к анонимному идентификатору устройства, ограничен 7 днями и 100 ответами. С одного IP можно начать не больше 2 пробных периодов за 30 дней.
- **Квоты держат расходы ниже цены подписки.** По умолчанию 500 ответов в месяц на подписчика и не больше 10 вопросов в минуту.

## Сколько это стоит

Один ответ — это примерно 250 входных токенов (характер бота, сведения о стриме, вопрос) и до 300 выходных (короткое размышление и ответ). На `claude-opus-5-5` ($4 / $20 за 1 млн токенов) выходит около **$0.005–0.007 за ответ**:

| | ответов | расход на Claude |
|---|---|---|
| Пробный период (лимит) | 100 | ≈ $0.6 |
| Pro, лимит в месяц | 500 | ≈ $3 из $8 подписки |

Это оценка. Реальную цену смотрите в Usage-отчёте Anthropic Console после первых дней работы и при необходимости меняйте `PRO_MONTHLY_LIMIT` или `AI_MODEL`. Комиссию Lemon Squeezy тоже учитывайте: примерно 5% + $0.50 с платежа.

## Переменные окружения

| Переменная | Обязательна | По умолчанию | Что это |
|---|---|---|---|
| `ANTHROPIC_API_KEY` | да | — | ключ из console.anthropic.com |
| `LS_STORE_ID`, `LS_PRODUCT_ID` | да | — | те же, что в `package.json` → `tiklive` |
| `AI_MODEL` | | `claude-opus-5-5` | модель Claude |
| `AI_EFFORT` | | `low` | глубина размышлений (`low` / `medium` / `high`) |
| `PRO_MONTHLY_LIMIT` | | 500 | ответов на подписчика в месяц |
| `TRIAL_DAYS`, `TRIAL_LIMIT` | | 7, 100 | длительность и лимит пробного периода |
| `TRIALS_PER_IP` | | 2 | новых пробных периодов с одного IP за 30 дней |
| `PER_MINUTE` | | 10 | вопросов в минуту на одного пользователя |
| `MAX_CONCURRENT` | | 8 | одновременных запросов к Claude |
| `DATA_DIR` | | `./cloud-data` | где хранить счётчики (`state.json`) |
| `TRUST_PROXY` | | — | `1`, если сервер стоит за прокси (Render, Railway, Fly, nginx) |
| `PORT` | | 8080 | порт |

## Запуск

Локально:
```bash
cd tiklive-studio
ANTHROPIC_API_KEY=sk-ant-... LS_STORE_ID=12345 LS_PRODUCT_ID=67890 npm run cloud
```

Docker на любом VPS (за HTTPS-прокси, например Caddy или nginx):
```bash
cd tiklive-studio
docker build -f cloud/Dockerfile -t tiklive-cloud .
docker run -d --restart=always -p 8080:8080 -v tiklive-data:/data \
  -e ANTHROPIC_API_KEY=sk-ant-... -e LS_STORE_ID=12345 -e LS_PRODUCT_ID=67890 tiklive-cloud
```

Render или Railway: создайте Web Service из репозитория. Root directory — корень репозитория, Dockerfile — `cloud/Dockerfile`. Задайте переменные из таблицы и подключите постоянный диск в `/data`, иначе счётчики будут сбрасываться при каждом деплое.

## Подключение приложения

Впишите адрес сервера (обязательно **https**) в `package.json`:
```json
"tiklive": { "cloudUrl": "https://ai.ваш-домен.com", ... }
```
и пересоберите приложение. Во вкладке «🤖 ИИ» режим «☁ Облако TikLive» включён по умолчанию, стримеру ничего настраивать не нужно. Режим «🔑 Свой ключ» остаётся для тех, кто хочет платить Anthropic напрямую.

Проверка: `curl https://ai.ваш-домен.com/health` должен вернуть `{"ok":true}`.

## API

`POST /v1/ai/answer`, заголовок `Authorization: Bearer <ключ лицензии>` (без него запрос считается пробным):
```json
{ "question": "...", "nickname": "...", "persona": "...", "streamInfo": "...", "maxChars": 220, "instanceId": "...", "deviceId": "..." }
```
Ответ `200 {"answer": "...", "quota": {"plan": "pro", "used": 12, "limit": 500}}`. Ошибки: `402` — нет подписки или пробный период закончился, `429` — квота или слишком частые вопросы, `502` — ошибка Claude, `503` — сервер лицензий недоступен или сервер перегружен.
