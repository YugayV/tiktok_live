# TikLive Studio

Локальный инструмент для интерактивных эфиров TikTok LIVE (по мотивам TikFinity): алерты, правила «событие → действие», цели, мини-игры, TTS, экономика очков зрителей и автоматизация OBS. Работает у вас на компьютере, бесплатно, без подписок.

## Быстрый старт

```bash
cd tiklive-studio
npm install
npm run demo        # демо-режим: симулятор событий, можно настраивать без эфира
# или
npm start           # обычный режим
```

Откройте **http://127.0.0.1:8787/**, введите `@username` стримера (который сейчас в эфире) и нажмите «Подключить».

### Настольное приложение (Electron)

```bash
npm run desktop          # окно приложения + иконка в трее
npm run dist:win         # установщик и портативный .exe → dist/
npm run dist:mac         # .dmg (собирается на macOS)
npm run dist:linux       # .AppImage
```

Готовые установщики для Windows, macOS и Linux собирает GitHub Actions (`.github/workflows/desktop.yml`) при каждом push или по кнопке «Run workflow»; скачать их можно во вкладке Actions → артефакты. Сборки не подписаны, поэтому при первом запуске Windows SmartScreen и macOS Gatekeeper покажут предупреждение.

В настольной версии закрытие окна сворачивает программу в трей: сервер и оверлеи OBS продолжают работать. Настройки хранятся в папке пользователя (`%APPDATA%/TikLive Studio/data` в Windows). Горячая клавиша **Ctrl+Shift+F12** экстренно останавливает нажатия клавиш из любой программы.

Требуется Node.js 20+. Порт и адрес меняются переменными `PORT` и `HOST`. По умолчанию сервер слушает только `127.0.0.1`: у панели нет пароля, поэтому не открывайте её в сеть.

## Оверлеи для OBS / TikTok LIVE Studio

Добавьте источник «Браузер» с одним из адресов (все есть на вкладке «Оверлеи», с превью и кнопкой копирования):

| Виджет | URL | Параметры |
|---|---|---|
| Алерты + звук + TTS | `/overlay/?w=alerts` | `&audio=0`: без звука |
| Цели | `/overlay/?w=goals` | `&goal=ID`: одна цель |
| Чат | `/overlay/?w=chat` | `&all=1`: также подарки и подписки, `&max=12` |
| Топ | `/overlay/?w=top` | `&by=diamonds\|likes\|chats\|points`, `&n=5` |
| Счётчик | `/overlay/?w=counter` | `&metric=likes\|viewers\|diamonds\|follows\|shares` |
| Колесо фортуны | `/overlay/?w=wheel` | `&size=500` |
| Голосование | `/overlay/?w=poll` | |
| Битва подарков | `/overlay/?w=battle` | |
| Очередь песен | `/overlay/?w=songs` | `&n=5` |
| Проигрыватель YouTube | `/overlay/?w=player` | `&video=0`: только звук, `&width=640&height=360` |
| Ответы ИИ | `/overlay/?w=ai` | `&sec=12`: сколько секунд показывать |
| Только звук/TTS | `/overlay/?w=audio` | |

Для звука и озвучки в OBS включите у источника «Управлять аудио через OBS». Если в вашей сборке OBS браузерный TTS молчит, откройте `/overlay/?w=audio` в обычном браузере и захватывайте его звук.

## Возможности

**Правила (триггер → действия)**
- Триггеры: подарок (по названию, по диапазону 💎), команда или слова в чате, RegExp, подписка, репост, каждые N лайков, вход зрителя, саб, вопрос, достигнутая цель, любое событие.
- Фильтры: роль (все, подписчики, сабы, модераторы), список username.
- Кулдауны: общий и на каждого зрителя. Приоритет. Флаг «остановить проверку остальных правил».
- Повтор «за каждый подарок в серии»: 10 роз дают 10 срабатываний (с лимитом).
- **Цена в очках**: зритель тратит накопленные очки на команды (например `!tts`).
- Действия: алерт (стили, картинка или GIF, звук, конфетти, картинка подарка), TTS, звук, изменение цели, начисление очков, колесо фортуны, OBS (сцена, показ или скрытие источника), webhook (Streamer.bot, Home Assistant, Minecraft-плагины и т.д.), своё событие оверлея.
- Кнопка «▶ Тест» у каждого правила.

**🤖 Ответы ИИ на вопросы зрителей (Claude)**
- Зрители спрашивают `!ai вопрос` / `!вопрос` / `!бот` или через функцию «Вопросы» TikTok. Ответ выводится алертом, озвучивается и показывается в оверлее `?w=ai`.
- На вкладке «ИИ» задаются характер бота и сведения о стриме (игра, расписание, правила). Ответы короткие и на языке зрителя.
- Расходы под контролем: запросы идут по одному, есть лимит в минуту и кулдаун на зрителя, ответы проходят фильтр запрещённых слов и ссылок.
- **Облако TikLive (по умолчанию):** вопросы уходят на ваш сервер (`cloud/`). Ключ Anthropic хранится там, и там же проверяется подписка, поэтому стримеру ничего настраивать не нужно, а обойти оплату правкой приложения нельзя. Развёртывание описано в [cloud/README.md](cloud/README.md).
- **Свой ключ (по желанию):** стример может указать собственный ключ Anthropic API ([console.anthropic.com](https://console.anthropic.com)) в настройках или в переменной `ANTHROPIC_API_KEY`. Модель по умолчанию `claude-opus-5-5` с низкой глубиной размышлений (быстро и недорого). Если модель откажется отвечать по соображениям безопасности, API автоматически повторит запрос на подходящей резервной модели (`fallbacks: "default"`).

**🎵 Очередь заказа песен**
- `!sr название или ссылка YouTube` — заказать, `!np` — что играет, `!wrongsong` — отменить свой заказ, `!skip` — пропустить (модераторы). Команды настраиваются.
- Ограничения: число песен на зрителя, размер очереди, цена в очках, режим «только YouTube», защита от повторов.
- Сабы попадают в очередь с приоритетом, подарок от 5💎 поднимает песню зрителя выше.
- Оверлей `?w=player` сам проигрывает YouTube-ссылки и переходит к следующей песне. Название трека подтягивается автоматически. Обычные названия показываются в очереди — их включаете вы.

**🎮 Управление играми с клавиатуры**
- Действие «Нажать клавиши» в правилах: `space`, `w`, `ctrl+shift+a`, последовательности `w, w, space`, удержание, повторы, клики мышью (`lmb`, `rmb`).
- Пример: каждая роза = прыжок (по одному нажатию на каждый подарок в серии), `!left` = шаг влево.
- Безопасность: выключено по умолчанию, лимит нажатий в секунду, ограниченная очередь, аварийная остановка кнопкой или клавишами Ctrl+Shift+F12.
- Windows: SendInput со скан-кодами, поэтому нажатия видят и игры. Если игра запущена от администратора, TikLive тоже нужно запускать от администратора. Linux: нужен `xdotool`. macOS: только короткие нажатия без мыши, нужно разрешение «Универсальный доступ».

**В чём эффективнее TikFinity**
- Серверная **очередь алертов с приоритетами**: крупный донат идёт вне очереди, все экраны OBS синхронны, есть пауза и пропуск.
- **Антиспам**: одинаковые подарки одного зрителя склеиваются в один алерт «×N», дубликаты событий от TikTok отбрасываются, серийные подарки учитываются один раз по окончании серии.
- **Автопереподключение** с экспоненциальной задержкой при обрыве или окончании эфира. Оверлеи сами переподключаются к серверу.
- **Экономика очков зрителей**, которая сохраняется между стримами (за чат, лайки, подарки, подписки и репосты). Курсы настраиваются.
- **Мини-игры**: колесо фортуны с весами секторов, голосование в чате (один голос на зрителя, можно переголосовать), битва подарков двух команд (`!team1` / `!team2`).
- **Аналитика**: 💎/мин и ❤️/мин, график активности, пик зрителей, топы донатеров, лайкеров и чаттеров, экспорт сессии в CSV.
- **Фильтр**: запрещённые слова и ссылки вырезаются из TTS и алертов.
- **Симулятор эфира** и тестовые события, чтобы всё настроить без реального эфира.
- Без облака и подписок: конфигурация хранится в `data/config.json`.

**Бесплатно навсегда:** алерты, правила, цели, очки зрителей, оверлеи чата, топа и счётчиков, TTS, аналитика, симулятор.
**Pro** (первые 7 дней бесплатно, без привязки карты): ответы ИИ, заказ песен, управление играми, колесо, голосования и битвы, автоматизация OBS, webhooks. Состав Pro задаётся в `PRO_FEATURES` в `src/license.mjs`.

Когда пробный период заканчивается, платные функции тихо отключаются (в журнале появляется строка «🔒 нужна подписка Pro»), а бесплатные продолжают работать. Сверху в панели видна плашка с остатком дней и кнопкой оплаты.

### Как подключить оплату (Lemon Squeezy)

Lemon Squeezy принимает карты, считает налоги, выставляет чеки и сам списывает деньги каждый месяц. Свой сервер не нужен: приложение только проверяет ключ лицензии через их публичный License API.

1. Зарегистрируйтесь на lemonsqueezy.com и создайте магазин.
2. Создайте продукт **TikLive Pro**: тип **Subscription**, $8, Monthly. Пробный период в Lemon Squeezy **не включайте**: 7 бесплатных дней приложение даёт само, без карты.
3. В настройках продукта включите **License keys**. Лимит активаций — по желанию, например 2 ПК на ключ. Ключ, выданный к подписке, сам истекает, когда подписка прекращается.
4. Впишите данные в `package.json`:
   ```json
   "tiklive": {
     "checkoutUrl": "https://ВАШ-МАГАЗИН.lemonsqueezy.com/buy/xxxxxxxx",
     "storeId": 12345,
     "productId": 67890,
     "priceLabel": "$8 / месяц",
     "trialDays": 7,
     "cloudUrl": "https://ai.ваш-домен.com"
   }
   ```
   `storeId` и `productId` есть в панели Lemon Squeezy. Ключи от других магазинов и продуктов приложение отклоняет.
5. Проверьте в **Test mode** Lemon Squeezy: оформите тестовую подписку, активируйте ключ на вкладке «💎 Pro», затем отмените подписку и нажмите «Проверить подписку».
6. Соберите установщики (`npm run dist:win` или через GitHub Actions) и распространяйте их.

**Как работает проверка.** Ключ проверяется при запуске и затем каждые 12 часов. Без интернета Pro работает ещё 7 дней. Пробный период и лицензия подписаны ключом, привязанным к компьютеру, и продублированы в `~/.tiklive/state.json`. Поэтому переустановка, удаление данных, правка файла или перевод часов назад пробный период не продлевают.

**Честно о защите.** ИИ-ответы защищены по-настоящему: их выдаёт ваш сервер и только по действующей подписке (см. `cloud/`). Остальные Pro-функции (песни, клавиатура, игры, OBS, webhooks) работают локально, и их проверку опытный пользователь может вырезать из кода. Для них это защита от случайного обхода, а не DRM.

> Lemon Squeezy подходит не для всех стран продавца. Проверьте, что он выплачивает в вашу страну. Если нет, клиент лицензий в `src/license.mjs` (методы `activate` / `validate` / `deactivate`) можно заменить на Paddle, Gumroad или свой сервер. Остальное приложение работает только через `license.can(feature)`.

## Устройство

```
server.mjs           запуск из командной строки
electron/main.mjs    настольное приложение (окно, трей, горячая клавиша)
src/server-app.mjs   HTTP API + статика + WebSocket-хаб
src/tiktok.mjs       подключение к TikTok LIVE (tiktok-live-connector) + автопереподключение
src/normalize.mjs    приведение событий разных версий протокола к одному формату
src/rules.mjs        движок правил (фильтры, кулдауны, стоимость, повторы)
src/queue.mjs        очередь алертов с приоритетами и склейкой
src/stats.mjs        аналитика сессии, цели, очки
src/games.mjs        колесо, голосование, битва подарков
src/obs.mjs          клиент obs-websocket v5
src/ai.mjs           ответы ИИ (Claude API)
src/songs.mjs        очередь заказа песен
src/keyboard.mjs     нажатия клавиш (Windows SendInput / xdotool / osascript)
src/license.mjs      пробный период и подписка Pro (Lemon Squeezy License API)
cloud/               сервер ИИ-ответов: ключ Anthropic, проверка подписки, квоты
src/studio.mjs       связывает всё вместе
public/              панель управления и оверлеи (vanilla JS, без сборки)
```

Тесты: `npm test`.

> Подключение к TikTok LIVE идёт через неофициальную библиотеку [tiktok-live-connector](https://github.com/zerodytrash/TikTok-Live-Connector). TikTok может менять протокол. При частых ошибках подписи укажите в настройках бесплатный ключ Euler Stream.
