Установка

Если браузер или Windows предупреждают о файле — это нормально для новой программы без платной подписи кода.

🪟 Windows 10 / 11

  1. Нажмите «Скачать для Windows» — загрузится TikLive-Studio-Setup.exe.
  2. Если Edge/Chrome пишет «файл скачивают редко» — ⋯ → Сохранить (или «Сохранить всё равно»).
  3. Запустите файл. Если появится синее окно «Windows защитила компьютер» — Подробнее → Выполнить в любом случае.
  4. Выберите папку → Установить. Ярлык появится на рабочем столе.
  5. Разрешите доступ в брандмауэре для частных сетей — это нужно оверлеям в OBS.
Обновления ставятся автоматически: при выходе новой версии в программе появится кнопка «Перезапустить и обновить».

🍎 macOS · 🐧 Linux

  1. macOS: откройте .dmg, перетащите программу в «Программы». При первом запуске — правый клик → Открыть.
  2. Linux: скачайте .AppImage, дайте права на запуск (chmod +x) и запустите.
  3. Для управления играми на Linux установите xdotool, на macOS разрешите «Универсальный доступ».

📦 Без установки

  1. Версия «Windows без установки» запускается из любой папки, но обновляется вручную — скачайте новую с этого сайта.

Вопросы

Нужен логин и пароль от TikTok?

Нет. Программа читает публичные события эфира по нику стримера (@username). Пароль и вход в аккаунт не нужны.

Это безопасно? Почему Windows предупреждает?

Предупреждение SmartScreen появляется у любой новой программы без платного сертификата подписи кода. Установщик собирается из открытого исходного кода на GitHub.

Работает с TikTok LIVE Studio и OBS?

Да. Оверлеи — это обычные веб-страницы, их добавляют как источник «Браузер» в OBS, Streamlabs или TikTok LIVE Studio. Фон прозрачный.

Что будет после 7 дней пробного периода?

Бесплатные функции продолжат работать. Pro-функции (ИИ, песни, клавиатура, игры, OBS, webhooks) отключатся, пока вы не оформите подписку.

Как отменить подписку?

По ссылке в письме об оплате, в любой момент. Pro будет работать до конца оплаченного месяца.

Программа должна быть открыта во время эфира?

Да, она получает события эфира и отдаёт их оверлеям. Закрытие окна сворачивает её в трей — оверлеи продолжают работать.

Какие требования к компьютеру?

Windows 10/11 64-bit (или macOS, Linux), 4 ГБ ОЗУ, около 400 МБ на диске, интернет.
